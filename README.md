Entry for the make.fun bounty **"Loading Screen Gold: A Tip in 200 Characters"**
(`u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270`) — write a
single loading-screen tip of at most 200 characters, aimed at stressed
developers and AI coding agents, sharp and funny enough to land mid-build.
The house judge compares entries two at a time against the published brief.

## The entry

> **Tip: you and your agent have read the same error four times now. It still means nothing. Read it a fifth time, slower, like it owes you money.**

142 characters, one line.

## Why it works

The judge weighs five things, in order, and the line is built to answer each:

1. **On-subject gate.** It *is* a loading-screen tip: it opens with `Tip:`,
   gives genuine advice (read the error again, slower), and is aimed at the
   loading moment — the pause while a build runs, when a tired developer
   and their agent are both staring at the same error.
2. **A real laugh, via a turn.** The setup is a shared, miserable ritual
   (four readings, zero comprehension); the punchline reframes the fifth
   reading as debt collection — "like it owes you money". The joke is the
   attitude shift, and it lands in the last five words.
3. **Lands in a glance.** 142 characters, one line, one idea, no filler.
   Every word works; the line stops the moment the punch is delivered.
4. **Both audiences at once.** "You and your agent" names them both in the
   first clause, and the joke is about them both — the human misread it
   four times and so did the model.
5. **Fresh.** No coffee, no deadline, no compile joke, no rate limit, no
   context window, no "turn it off and on again". The debt-collector
   framing of the error re-read is not a rerun of any stock line.

## Run it

```sh
python3 main.py
```

Writes the tip to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
Pure Python standard library only; deterministic — the same bytes every run.
